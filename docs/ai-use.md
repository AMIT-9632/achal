# AI-use disclosure

The HSC-27 guidelines require disclosure of AI assistance. Team ACHAL used an AI assistant (Claude,
by Anthropic) to help with research summaries, planning, code scaffolding and documentation drafts.
All design decisions, code review, testing and final content are the team's responsibility.
The AI risk engine inside ACHAL is classical ML (scikit-learn) trained only on our own synthetic data.
